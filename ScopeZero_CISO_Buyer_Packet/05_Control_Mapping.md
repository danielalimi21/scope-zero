# ScopeZero Control Mapping

## Control Outcomes

| Buyer Need | ScopeZero Capability |
| --- | --- |
| Prevent agent misuse of valid access | Mission-scoped action authorization |
| Govern autonomous tool calls | Pre-execution allow/block/approval decisions |
| Reduce prompt-injection blast radius | Prompt influence detection and quarantine |
| Prevent sensitive data movement | Data classification and egress controls |
| Stop cloud privilege escalation | Privilege-impact detection and approval gates |
| Prove what happened | Hash-chained evidence ledger |
| Support SOC workflows | SIEM export and decision telemetry |
| Govern MCP tool calls | MCP proxy enforcement |
| Support policy oversight | Policy versioning and approval workflow |
| Integrate into enterprise identity | OIDC/JWKS-compatible authentication path |

## SOC Value

ScopeZero events can answer:

- Which agent requested the action?
- Who delegated authority?
- Which mission applied?
- Which tool was called?
- Which operation was attempted?
- What data class was involved?
- Was the destination approved?
- Was prompt influence detected?
- Was the action allowed, blocked, quarantined, redacted, or routed to approval?
- What evidence hash proves the decision?

## CISO Value

ScopeZero turns agent governance from policy language into runtime enforcement.

Instead of asking teams to trust that agents will stay inside instructions, ScopeZero enforces the mission at the tool-call boundary.

## AI Platform Value

AI platform teams can ship agents with:

- clear mission contracts
- reusable authorization patterns
- vendor-neutral connector boundaries
- approval paths for high-impact actions
- auditable runtime evidence

## Compliance Value

ScopeZero helps establish:

- access governance evidence
- change-control evidence
- approval evidence
- incident response evidence
- policy enforcement evidence
- sensitive data control evidence
