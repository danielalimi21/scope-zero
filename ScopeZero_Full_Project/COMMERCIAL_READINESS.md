# ScopeZero Commercial Readiness

## Current Commercial Status

ScopeZero is ready to pitch as a **commercial pilot product**.

It is not yet a fully managed commercial SaaS, but it is strong enough to sell a paid pilot because it has:

- working gateway
- browser demo
- SDK
- MCP proxy
- OpenAPI contract
- automated tests
- evidence ledger
- policy engine
- security review
- deployment path
- buyer pitch package
- readiness report

## What You Can Sell Today

Sell:

> A controlled pilot that proves agent tool calls can be authorized, blocked, approved, and evidenced before execution.

Do not sell:

> A finished enterprise-wide SaaS platform.

## Best First Customers

Target buyers who already have or are building agents:

- AI platform teams
- security engineering teams
- identity teams
- SOC/SIEM teams
- data security teams
- cloud security teams
- companies experimenting with MCP

## Strongest First Message

> Cisco buying Astrix validates non-human identity security. ScopeZero extends that market from identity governance to action authorization: not just "who is this agent?" but "is this exact action allowed?"

## What Is Missing For Full Commercial SaaS

Required:

- hosted deployment
- customer tenant management
- real IdP setup
- managed Postgres
- vault/KMS
- real connector worker
- SIEM integration
- production UI for policy/approval
- support process
- legal docs
- privacy policy
- terms of service
- external security assessment

## Recommended Next Move

Do not build endlessly before talking to buyers.

Do this:

1. Pick 20 target people.
2. Send the short pitch.
3. Ask for 20 minutes of blunt feedback.
4. Show the demo.
5. Ask which workflow they would pilot.
6. Offer the paid design pilot.

## Commercial Readiness Verdict

ScopeZero is not "done" as a company.

But it is now coherent enough to pitch seriously:

- clear category
- clear pain
- clear demo
- clear buyer
- clear pilot package
- clear technical architecture
- clear pricing hypothesis
- clear next integration path
