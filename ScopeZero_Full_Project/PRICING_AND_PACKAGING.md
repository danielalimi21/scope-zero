# ScopeZero Pricing And Packaging

## Commercial Position

ScopeZero should be sold first as a **paid design pilot** for high-risk enterprise agent workflows.

Do not sell it initially as a broad platform replacement. Sell a narrow outcome:

> ScopeZero will govern one autonomous agent workflow and prove that out-of-scope tool actions can be blocked before execution with SOC-ready evidence.

## Package 1: Technical Validation

Price target: **$10k-$25k**

Duration: 2-3 weeks

Best for:

- cyber product teams
- AI platform teams
- innovation teams
- early technical evaluators

Includes:

- architecture review
- local gateway demo
- SDK walkthrough
- MCP proxy walkthrough
- one custom mission contract
- one policy review session
- readiness report
- written technical findings

Deliverable:

- "ScopeZero fit assessment" for one agent workflow

## Package 2: Controlled Pilot

Price target: **$50k-$150k**

Duration: 6-10 weeks

Best for:

- regulated enterprise
- AI platform team
- CISO organization
- SOC/identity/cloud security team

Includes:

- one internal agent workflow
- two or three tool boundaries
- one IdP integration path
- one SIEM export path
- one approval gate
- one policy package
- deployment support
- evidence review
- weekly pilot meetings

Success criteria:

- all agent tool calls pass through ScopeZero
- at least one out-of-scope action is blocked in test
- at least one approval workflow is generated
- SOC receives usable evidence
- security team signs off on go/no-go for expansion

## Package 3: Enterprise Expansion

Price target: **$150k-$500k+ annual**

Best for:

- multiple agent teams
- production agent governance
- regulated workflows
- platform buyer

Pricing dimensions:

- number of governed agents
- number of tool connectors
- SIEM/IdP/vault integrations
- data retention requirements
- deployment model
- support level

Includes:

- production deployment design
- managed policy packages
- multiple workflows
- expanded connector coverage
- observability and audit integration
- security review support
- quarterly risk review

## Suggested Pricing Metric

Start simple:

- per governed agent workflow
- plus connector package
- plus deployment/support tier

Avoid pricing only by API call at the beginning. Buyers understand workflows and risk better than raw tool-call volume.

## First Paid Offer

Best first paid offer:

> "For $50k, ScopeZero will run a six-week controlled pilot around one internal AI agent workflow, governing two tools and producing SIEM-ready evidence for blocked out-of-scope actions."

## Why Paid Pilot

A free proof-of-concept can create low commitment. A paid pilot forces:

- real buyer ownership
- real workflow selection
- real integration discussion
- real success criteria
- real urgency

## What Not To Promise Yet

Do not promise:

- full production SaaS readiness
- every connector
- replacing IAM/DLP/SIEM
- guaranteed prompt-injection prevention
- finished SOC2 certification

Promise:

- pre-execution authorization layer
- mission-scoped policy
- evidence trail
- controlled pilot outcome
- integration roadmap
