Use this folder for first conversations with CISOs, AI platform leaders, cyber investors, and strategic security companies.

1. `ScopeZero_One_Pager.md` - send or convert to PDF.
2. `ScopeZero_90_Second_Demo_Script.md` - use for a short Loom/video demo.
3. `ScopeZero_Outreach_Copy.md` - email and LinkedIn messages.
4. `ScopeZero_Target_Customers.csv` - target account list.
5. `ScopeZero_Discovery_Call_Script.md` - use during calls.
6. `ScopeZero_Mini_Deck.md` - 7-slide pitch outline.
7. `ScopeZero_Objection_Handling.md` - answers to likely pushback.

> ScopeZero is a vendor-neutral action authorization gateway for autonomous AI-agent tool calls.

> The agent was authorized. The action was not.
