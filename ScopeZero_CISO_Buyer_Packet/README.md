# ScopeZero CISO Buyer Packet

## Purpose

This packet is designed for security, AI platform, identity, cloud security, and SOC leaders evaluating runtime controls for autonomous AI-agent tool use.

## Positioning

ScopeZero is a vendor-neutral action authorization gateway for autonomous AI-agent tool calls.

IAM answers whether an agent has access.

ScopeZero answers whether a specific autonomous action is authorized before execution.

## Review Guidance

The recommended review order is:

1. Executive brief.
2. CISO proof report.
3. Product architecture.
4. Security review.
5. Pilot proposal.
6. Product explanation and technical decision-engine deep dive.
7. Demo access and evaluation guide.
8. Interactive walkthrough in `demo/index.html`.
9. Short pitch video in `pitch_video/scopezero-pitch-video-voiced.mp4`.

The strongest evaluation question is:

> Can ScopeZero stop an autonomous agent action before the tool call executes, while producing evidence that security teams can trust?
